## 2. 质检方法

19 条规则（QC01–QC19），分五组；每条异常记录**只报一次**（多规则命中合并），并给出规则号便于复核：

| 组 | 规则号 | 检查什么 |
| --- | --- | --- |
| 结构 | QC01–QC03 | 14 列表头一致、UTF-8 BOM、必然字段非空 |
| 唯一 | QC04–QC05 | `记录编号` 唯一；`作答事件编号`+最高 `修订版本` 唯一 |
| 取值 | QC06–QC08 | 评分状态 ∈ {已评分,待评分,未作答}；已评分 0≤得分≤满分；待评分/未作答的得分与评分点必须为空 |
| 一致性 | QC09、QC11–QC19 | 评分点和 = 得分；评分点前缀 = 材料编号；客观题答案与评分一致性；不等式解集端点方向 |
| 外键/规则 | QC10、QC12–QC13 | 材料存在、主题与材料表一致、材料在该节点可用题目内、提交时间 ≥ 节点日期、解答过程仅解答题 |

## 4. 缺失与“信息不足”的处理

- **待评分 6 条、未作答 5 条一律不记 0 分**：分别进 `observed.pending` / `observed.unanswered`，不参与得分率分子分母。
- **D17 只有 N01 的 4 条记录，N02 无记录**：诊断输出 `coverage.N02 = 0.0`、`flags` 标 `记录不足`，不推断“未掌握”。
- **覆盖度**：分母取该节点可用题目数（N01=27、N02=45），同时输出 `union=54` 口径作对照；D01 实测 N01 0.4444、N02 0.2222。
- **置信度**：观测 <5 条记 `low`，5–9 记 `medium`，≥10 记 `high`；低置信指标必须写进 `notes`。

## 5. 重复与修订

- 7 个 `作答事件编号` 存在 `修订版本=2`，折叠后取 v2（`revisions_folded=7`），旧版本保留在原始表里可回溯。
- 无整行完全重复的记录。
- 低风险观察（不改数，写进复核说明）：7 条 v2 记录的复核时间戳呈连续秒级递增，疑似程序生成；19 组跨学生在同一秒提交；D29 的 15 条记录集中在 2026-06-18。以上均不影响统计口径，但在答辩问“数据真实性”时应主动说明是模拟数据特征。

## 6. 局限（照抄进 `diagnosis.limitations`）

1. 抽样作答而非全员全题：个体结论只对“有记录的题目”成立。
2. 不同节点可用题目集合不同，跨节点均分不可比，只看指标层趋势。
3. 模拟数据无作答时长、无提示使用记录，无法分析“努力程度/求助行为”。
4. 8 份教材切片未标主题，材料覆盖的“范围完整性”待人工归属后补齐。
